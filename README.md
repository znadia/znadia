## Compétences Data

- **Langages** Python (Pandas, NumPy, Matplotlib, Seaborn, scikit-learn...), SQL
- **Bases et entrepôts de données** MySQL, Snowflake, dbt
- **Environnements** Jupyter Notebook, Google Colab
- **Visualisation** Power BI (Power Query, DAX), Excel (VBA, macros)
- **Méthodes** nettoyage et qualité des données, statistiques, machine learning, storytelling
